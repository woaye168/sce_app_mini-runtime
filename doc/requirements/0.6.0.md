# 0.6.0 需求 —— 局域网/外网联机 + 在线增量分发客户端

## 背景

本地服务器（0.5.x）已支持真本地 host + 多账号多开同局。本版本把「同机多开」扩展为「跨机联机 + 在线分发测试」：朋友在自己电脑上跑一个轻量启动器，从你机器的本地服务器增量拉取游戏，连上同一局。支持局域网与 IPv4 外网（路由器端口转发）。

**本质**：本地服务器 = 分发源 + 游戏 host。你改代码 → bgd 构建 → staging 变 → manifest 自动重建 → 对端下次启动增量更新。

## 架构

```
房主（你）                                对端（朋友）
─────────                                ─────────
本地服务器 host（TCP 5003 控制 + UDP 5053 会话）   mini-client.exe（轻量启动器，唯一下载体）
 + HTTP 文件服务（分发 staging，新端口）            ↓ 双击：输入 IP/端口
 staging 目录（bgd 构建产物，改代码自动变）          ↓ 拉 manifest → 比对本地缓存
 manifest.json（文件清单+尺寸+xxhash）              ↓ 引擎缺失 → 官方 OSS 免鉴权下载（400MB，仅首装）
                                              ↓ 游戏文件增量下载（只下变化的）
                                              ↓ 有更新提示 + 异步进度（不卡界面）
                                              ↓ 输入 userid（房主分配 90000001 起）
                                              合成凭证（login=1 + token=local-<userid>）进游戏
```

## 关键设计决策（与用户确认）

1. **引擎下载免 token**：官方 update-info + OSS 通道本就免鉴权（0.2.0 起 0 依赖）。对端直连官方下引擎，房主零带宽压力，官方升级自动跟随。**不涉及房主任何凭证**（TapTap token 绝不分发）。
2. **对端输入**：exe 内 GUI 输入 IP / 端口 / userid。
3. **绑定范围三态**：本地（127.0.0.1，默认）/ 局域网（0.0.0.0）/ 外网（0.0.0.0 + 提示路由器转发）。

## R1 日志字体修复（顺手小修）

日志面板 `ui.monospace()` 等宽字体无中文字形 → 中文逐字分散。改正文比例字体（appsdk 壳已装中文字体）。

## R2 host 绑定范围三态

「本地服务器」页 host 启动加绑定范围选择（本地/局域网/外网，默认本地）。绑定 0.0.0.0 时界面显示本机局域网 IP（UDP 连 8.8.8.8 读源地址不真发包）供分享；外网模式提示路由器配置端口转发（TCP 5003 + UDP 5053 + HTTP 分发端口）。

## R3 HTTP 分发服务（host 侧新增）

host 启动时附带一个 HTTP 文件服务线程（独立端口，默认 5083 = 5003+80）：

- `GET /manifest` → staging 文件清单 `[{path, size, xxh64}]`（增量判定依据；改代码后自动重建——每请求实时扫 staging 算哈希，量小毫秒级）
- `GET /file?path=<相对路径>` → 单文件内容（路径穿越防护）
- 仅分发 staging 白名单目录内容
- 绑定地址跟随 R2 范围（本地模式不对外）

## R4 对端启动器（mini-client）

`src/bin/mini_client.rs` 独立二进制（eframe 小窗，复用 eframe 依赖）：

1. 连接界面：IP / 端口（默认 5003）/ userid 输入框（记忆上次，exe 旁 `mini_client.ini`）
2. 「连接」→ 异步（工作线程 + 进度回调，UI 不卡）：
   - 拉 manifest → 比对本地缓存（`exe 旁 cache/<项目>/`）
   - 引擎缺失 → payload 官方 OSS 下载（进度条）
   - 游戏文件增量下载（变化的逐文件下，进度条）
   - 有更新时界面提示「检测到更新，已增量同步 N 个文件」
3. 全量就绪 → 写合成凭证（按 userid）→ spawn 引擎客户端（`-host_ip/-host_port/-user/-local_test/-kcp_stream -map_path=<缓存staging>`）→ 启动器退
4. 缓存复用：二次启动无更新 = 秒开

## 出口闸（验收）
