## 背景

B 模式调试长期依赖官方云端 debug host（assign_host 分配）。本期目标 = 自建 host 第一形态「中继 host」（self-host.md §8 架构 A）：本地进程监听 127.0.0.1:5003 门面，TCP 控制面协议感知透传 + UDP KCP 会话 NAT 转发到云端真 host——不脱机，但统一入口、全流量可观、为真本地化占位。云端 host 保留为界面可选项。
