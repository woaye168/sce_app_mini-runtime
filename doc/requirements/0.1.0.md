# 0.1.0 需求：脱机登录与调试

> 日期：2026-08-21
> 状态：待开发（事实研究已完成，见 doc/research/offline-auth-debug.md）
> 来源：editor-runtime-mechanism.md（editor-patch 仓 doc/research）的 §5.4 待实测项与本仓承接

## 1. 背景与目标

`bgd_sce_tools` 生态的新应用 `sce_app_mini-runtime`（脱机运行时）。0.1.0 只交付两件事：

1. **脱机登录**：不打开星火编辑器 GUI，完成登录态的获取/保存/切换/验证。
2. **脱机调试**：不打开编辑器 GUI，对指定项目启动一次调试局（走官方 headless 通道），拿到可观测的结果。

明确**不做**（后续版本）：脱机发布（0.2.x）、自托管 lua 宿主（0.3.x）、多开并行、PIE 画面截取。

## 3. 验收标准

1. 凭证库能存 ≥2 份凭证并切换；切换后编辑器启动即为对应账号（或 headless 命令直接生效）。
2. 自登录：手机 TapTap 扫码一次，凭证文件落盘且 login_token/secret 可验证有效。
3. 对 test_res002 执行脱机调试：日志出现 assign_host 成功 + 游戏 on_enter_game，或明确报错；全程无 GUI 交互。
4. 凭证读取在编辑器已登录态下直接可用（零配置）。

## 4. 技术约束与事实基础（研究结论摘要，详见 doc/research/offline-auth-debug.md）

- 凭证 = 单文件明文 JSON：token（mac_key$kid）、access_token、login_token + login_token_secret（HTTP 签名对）。
- 签名：`md5(noise\ntime\ncontent_md5\nlogin_token\nlogin_token_secret)`；服务地址族 `https://<服务>-<env>.tapsce.cn:<端口>`（publisher 9000 / updater 9002 / login 9011 / assign_host `http://<_G.IP>:9007`）。
- 自登录 = TapTap OAuth2 device flow（`/oauth2/v1/device/code` + `/oauth2/v1/token` 轮询）。
- 编辑器 exe 启动形态（生产实证）：`-inner -winui_material_editor -winui_resource_store -editor_api_version=<n> -file_path=<项目>\project.sce`。
- 编辑器根目录推导：项目 `map_settings.json` api_version → 版本目录 → api_pak_version.json（bgd_sce_tools locate 链已有实现）。
- lobby 登录态是 entrance 长连接（native），headless 调试由官方流程自己处理，应用侧不碰。

## 5. 已知风险

| 风险 | 应对 |
| --- | --- |
| 凭证有效期未知（login_token 注释称「长期有效」未实测） | 验证功能先行；失效表现=验证失败→引导重新扫码 |
| 编辑器回写凭证文件（refresh_token） | 收割机制；切换只在编辑器关闭时做 |
| headless 弹窗卡死 | 超时杀进程 + 日志解析失败原因 |
| 调试局形态未实测（进程树/停止方式） | 0.1.0 开发期实测补记 |
| TapTap device flow 的 client_id 硬编码在官方 lua（`_G.client_id`） | 复用官方值；变更时从 xdeditor ui/login.lua 同步 |

## 6. 交付物

- egui 三标签页：凭证（库/切换/扫码登录/验证）、调试（项目/启动/停止/日志）、设置。
- CLI：`mini-runtime auth list|use|verify|login`、`mini-runtime debug start|stop --project <路径>`（供宿主/脚本）。
