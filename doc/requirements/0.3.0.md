## 背景

0.2.0 全链用的是「星火对战平台」引擎（update-info win 包 = tester scegame，MD5 实证一致）。但 mini-runtime 的定位是**代替星火编辑器**做便捷调试与发布，应默认使用「星火编辑器」运行时。运行时未来可切换扩展：

1. 星火编辑器-13 运行时（本期主攻，用户项目 api13）
2. 星火编辑器-2000 运行时（同架子，改 api 即可）
3. 星火对战平台 测试环境运行时（e.production.spark.xd.com_test）
4. 星火对战平台 正式环境运行时（e.production.spark.xd.com）

## 关键实证

- wineditor@147：`update-info?list=wineditor&api_version=13&variation=windows_editor` → OSS `wineditor/master/Version/147/windows_game.7z`（144MB）→ version-13/ 完整引擎 + 基座 res。
- login=1 闸门：startup/entrance/main.lua `after_update()` 里 `account.get_login_state() == 1` 才自动 account.login()；否则大厅停在登录按钮，日志抓取 90s 超时。
- account.save() 只序列化 account_data（不含 userid）——userid 只能走日志/内存。
