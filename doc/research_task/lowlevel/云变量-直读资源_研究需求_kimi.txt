# 研究目标

## 1. 渲染底层 API

能用底层 API 直接渲染图像、视频、模型、特效、spine 等。不是 `base.ui.*` 或 `imgui.*`——二者均有局限：

- 模型无法使用项目内本地模型文件（本地模型用法我完全不掌握）；
- 特效文件直接使用不显示，必须先经编辑器「数据编辑器」创建再关联；
- tiled 导入的图片集只有两种迂回方案，均有明显性能问题：A）双 panel 嵌套，内层显示图片集、外层 clip 剪裁出图元；B）用 sprites 载入图片集、静止一帧显示图元。

另：`canvas_texture_*` 可自绘纹理，但仅在「星火编辑器」内生效，发布到「星火对战平台」测试版一用即崩，前期研究未走通。

## 2. 云变量底层 API

能读写星火线上云变量数据。不是 `sce.s.*`、`base.s.*`、`score.*`——不够底层：云变量被分为多类型、各有签名，使用均计入读写次数，控制不灵活。理想目标是向星火数据存储服务器直读直写，以便灵活处理数据、建立更强的关联查询、优化读写性能。（`base.s.*`、`score.*` 仅服务端可调；`sce.s.*` 仅客户端可调。）

# 研究手段

源码溯源 + 逆向，可能需要：1）还原加密 lua，从入口逐个文件读源码找线索；2）读取所用 dll，找底层接口与调用签名；3）抓包逆向云变量协议。
